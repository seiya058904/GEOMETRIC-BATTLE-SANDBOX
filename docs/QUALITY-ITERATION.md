# GEOBATTLE 综合质量迭代

2026-10-13，Windows 本地实施。基线为 `d8e33c47aa9eb92c51ff98643976b8870761b162`，开始时工作树干净。本文对应当前源码、`dist/` 与根目录单 HTML；历史 V1/V2 报告保留，不作为本轮通过证据。

## 已实现

- 宽度 ≤760px 或高度 ≤540px 使用紧凑布局。CSS 输出布局令牌，抽屉控制器读取同一条件；844×390 横屏目录恢复滚动空间。打开面板后也检查触控目标，而非仅检查首屏。
- 抽屉焦点进入、Tab/Shift+Tab 循环、Escape、焦点归还和背景 inert；打开其他对话框先关闭抽屉。只在布局模式变化时关闭面板，避免同模式的视口高度变化打断搜索。
- 空预览数组稳定复用，让不可变布阵的静止帧缓存真正命中。交互、选择、镜头、画质、窗口和编队变化继续失效刷新；战斗模拟计时没有改变。
- 战斗时隐藏不可用目录及编辑栏；保留暂停、速度、人数、时间和返回。返回布阵恢复工具、目录筛选/搜索及镜头上下文。新增“近看 / 全图”，手动镜头暂停自动取景，触屏提示使用单指/双指措辞。
- 保留既有几何轮廓、攻击姿态和武器比例，近距离高/中画质增加红圆 / 蓝方的阵营标记，选中单位在低画质也保留；召唤物增加虚线环。低画质保留眩晕、倒地、恐惧和治疗/召唤/冰冻关键反馈；减少动态效果偏好禁止屏幕震动。没有放大物理碰撞体。
- 接入部署成功提示音，沿用既有轻重命中、射击、爆炸、治疗和结束合成音、10 声部上限、同类音间隔与压缩器。取消手势不播放部署成功音。
- 军阵档案增加盾面/背向、集中/错开枪阵、密集/分散三组共六个实验。每组固定人数、兵种、种子，只改变指定变量；使用普通 `schemaVersion: 1` 军阵，可编辑、撤销且不覆盖命名存档。提示承认盾兵会自主转向，不保证预期胜负。
- 战报先给胜负、时长和初始单位损失；保留伤害、治疗、贡献与可展开兵种明细。当前会话仅留最近两场快照，显示编队/种子变化与数据差异；刷新清空，无新增存档协议，也不把差异解释为胜负因果。

## 保护边界与工程范围

`src/sim/`、36 兵种定义及数值、部署校验、持久化与迁移协议均未改动。无友军伤害、1200 活动单位上限、固定步长和同种子确定性沿用原实现及回归。没有新框架、运行时依赖、联网服务或经济/地形/战役系统。

控制器只增加阶段布局、观察入口、实验与战报协调。新增 `src/ui/panels.js` 管理抽屉，`src/ui/reports.js` 管理最多两场快照，`src/data/experiments.js` 提供普通编队。未进行全仓重构；CSS 调整集中在既有响应式条件及本轮面板/阶段规则，历史未涉及样式保留。隐藏的战斗详情不再定时重建 DOM。

- **CONFIRMED-STATIC**：模拟/数据/存档模块未改；新增实验使用现有合法编队格式；战报最多两场且只驻留会话内存。
- **体验判断**：阶段收拢、近看入口、实验问题和战报对照有助于观察与重复实验，但尚无真实新手研究、可玩性或留存数据，不能宣称已证明学习效果或平衡。

## 本地运行与复现

直接用浏览器打开根目录 `GEOBATTLE-OFFLINE.html`；或运行 `node scripts/serve.mjs --dist` 后访问本机地址。生产目录与单 HTML 包含相同游戏脚本/样式，运行时无需 npm 或联网。

开发门禁为 `npm run check`、`npm test`、`npm run build`。浏览器脚本需要另行提供 Playwright，支持环境变量 `PLAYWRIGHT_MODULE`；本轮使用已有本地 Chromium 151 运行时，没有增加项目依赖。

完整新增功能检查：`node tests/v3-browser.mjs`；原生产回归：`GEOBATTLE_TEST_DIST=1 node tests/browser.mjs`；离线：`node tests/offline.mjs`；声音行为与受控截图：`node tests/v3-feedback.mjs`。这里的环境变量写法用于说明，PowerShell 使用 `$env:变量='值'`。

性能矩阵使用 `GEOBATTLE_QA_NATIVE_GPU=1`、`PERF_SECONDS=12`，三次独立启动 `node tests/performance.mjs`，冻结基线与当前生产版分别测量。同一1920×1080、DPR1、自动画质、固定场景种子、1×速度；不并行执行其他压力测试。

10分钟长测使用 `GEOBATTLE_LONGRUN=1`、`PERF_SCENE=none`、`LONGRUN_SECONDS=600`、`LONGRUN_MAX_SECONDS=900`、`LONGRUN_SPEED=1`、`LONGRUN_SCENE=300-vs-300`、`LONGRUN_RETURN_CYCLES=1`。每场由真实 RAF 自然完成；测试调度器交替调用同种子重赛与返回布阵/开始，核对原阵和完整结果，不加速跳结算。定期 CDP 读堆、不强制 GC；真实按钮操作另由功能回归覆盖。

构建字节校验：设置 `GEOBATTLE_BUILD_REPORT=evidence/v3/build-final.json` 后运行 `node scripts/verify-v2-build.mjs`。本轮不覆盖旧 V2 构建记录，不推送、部署或发布。

# GEOBATTLE · 36 兵种实际名册

表中数值直接取自 `src/data/units.js`，与本交付实现一致。全部兵种都遵循同一阵营、护甲、碰撞、命中和死亡规则。COST 仅供比较，不限制部署。

V2 保留全部36兵种和本表数值；图鉴使用中性身份颜色，队伍由准备阶段落点确定。全部36类型有半径边界单测、单一图鉴检查及真实72单位自然战斗观察，保存于 `evidence/v2/visual-final/`；具体最新生产验收以 `V2-QA-REPORT.md` 为准。

单位：速度为世界单位/秒，半径和射程为世界单位，CD/技能冷却为模拟秒。普通射程还允许命中目标身体半径与武器几何相交的边缘。

## 相对任务书的数值说明

全部 36 种预设的基础 HP、速度、身体半径、伤害、普通冷却、射程、护甲和参考 COST 保持原始建议值。没有隐藏时代克制、人数补偿、阵营加成或硬编码胜负。表中原始冲量实际除以目标质量的平方根，并受有限速度与衰减约束。

任务书未钉死的多段伤害、范围形状、质量、前摇、冲量、诱饵 HP、穿甲和技能首次准备时间在这里具体化。所有技能均已接入实际模拟；自然对战测试确认每个攻击兵种能造成真实伤害，每个主动技能兵种都在代表场景触发技能，治疗师单独验证寻找患者与实际恢复。竞技平衡和所有 36×36 配对胜率并未穷举。

## 可解释性

远程、体型、护甲、射程与伤害确实会形成巨大强弱差距。飞碟和无人机没有免疫近战；治疗师没有敌对攻击；召唤者死亡不抹除其已经生成的骷髅。查看单体详情中的目标、AI 状态、生命、攻击/技能冷却和真实战绩，可解释一场对战中的主要差异。

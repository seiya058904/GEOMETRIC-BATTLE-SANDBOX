# V2 部署与存档兼容

V2 保留 `schemaVersion: 1`、`geobattle.autosave.v1` 与 `geobattle.presets.v1`。UI 更新不需要改变现有 JSON 结构。ID、兵种、阵营、坐标、弧度朝向和 uint32 种子仍由同一验证器检查；文件与直接对象输入均保留 2 MiB UTF-8 上限。未知未来版本、重复或不安全 ID、未知兵种、非有限坐标/角度、重叠及超过 1200 个单位均明确拒绝。

## 准备阶段的不变量

世界尺寸为 2400 × 1350，中线 x=1200。完整兵种碰撞半径加 `PLACEMENT_GAP=2` 必须留在本方半场：红方中心 x≤1200−radius−2，蓝方 x≥1200+radius+2；世界边界仍按完整碰撞半径检查。这些是世界坐标规则，与缩放、DPR 和输入设备无关。

`teamForDeploymentPosition`、`validateHomeZone`、`resolvePlacementCandidate` 和 `validatePlacement` 是唯一规则来源。编辑器构造、载入、批量绘制、移动、旋转、复制、镜像与随机生成均遵守严格准备态校验。模拟并不调用部署区域校验；开战后的追击、弹丸、冲锋、闪现与召唤继续使用完整世界。

单击按落点确定阵营。笔刷/直线/矩阵锁定一次手势所属阵营，跨线候选跳过并汇报数量，完整手势只占一次撤销。粘贴保持相对几何和朝向，但完整落点必须处于同一半场，按该半场归属分队；碰撞/跨线时整组不提交且保留剪贴板。单队选区可以完整移入另一半场并改变归属；混合选区保持原阵营，不能部分改变归属。旋转非法则整体拒绝。全场镜像与“两军对调”同时反射 x、翻转阵营与朝向，保留 ID，允许完整撤销。

## 读取历史数据

1. 合法 V1 布阵按原坐标、阵营、兵种、ID 和种子读取；有限的多圈角度沿用原有规范化逻辑。
2. 旧跨区 V1 布阵先通过原有世界/碰撞/数据校验，再返回 `code: migration`、完整净化布阵 `value`、不兼容单位列表 `incompatible` 与原文本 `raw`。这不是可开战的成功结果。编辑器不会接受它，不自动改队、不丢兵、不自动移动。
3. 恢复界面可以只读展示该布阵，玩家可备份原 JSON、预览创建兼容副本、接受副本或取消。接受副本前不能把只读布阵作为正式编辑器/开战输入。
4. 损坏或未知版本文件不进入迁移；当前正式布阵保留不动。命名预设仍全部列出，含跨区预设的名称、日期与人数；载入跨区预设时单独进入恢复路径，不隐藏其他正常预设。

`validateFormation(input,{allowLegacy:true})` 仅用于历史读取与兼容检查；标准编辑器和写入路径不使用这个选项。它也不放宽世界边界、容量、碰撞、类型或数值要求。

## 显式创建兼容副本

`migrateFormation(input)` 返回新对象，原输入不变。保留所有单位的 ID、类型、原阵营、原朝向与种子，以及原数组顺序和总人数。已合法的单位位置不动。仅对不兼容单位，按大体型优先、ID 稳定排序：先尝试将跨区位置镜像回原阵营半场；中心带位置向本方合法边缘收回；冲突时在本方半场作确定性安全间距搜索。

若剩余空间不足或此有限搜索无法为所有单位找到合法位置，返回 `migration-space`，不会生成缺兵的“成功副本”。玩家继续保留原备份。副本可能改变原有相对军阵，因此恢复界面提供原阵容与兼容副本的只读预览，玩家显式创建才提交；不声称旧跨区对战的胜负保持不变。正常合法 V1 阵容不需这一步。

接受副本以一次 `Editor.setFormation` 载入，可完整撤销/重做。跨区命名预设可保存成新的名称，原预设继续保留；不要用默认阵型覆盖待恢复预设。

## 自动存档保护

`PresetStore.loadAutosave()` 对跨区、损坏、未知版本数据返回错误，并保留原始存储文本。该 store 后续 `saveAutosave()` 返回 `protected`，不会把默认示例或玩家新编辑静默覆盖到原槽位。第一次保存也会先检查原槽位，避免忘记读取就写入。读取权限失败同样锁住写入。

恢复界面取消后继续保护原槽位。只有完成备份并明确接受恢复/替换后，控制器才能调用 `releaseAutosaveProtection()`，再保存严格合法的正式阵型。quota 或权限写入失败仍由原有错误路径处理，内存布阵可以继续编辑/导出；失败不清空存储。原文备份包含未知字段，净化副本只包含已定义的安全字段。

## 自动化证据与限制

`tests/editor.test.js` 保留原有几何、事务、撤销、容量、随机确定性、JSON 和存储错误测试；仅将旧版“错误半场合法”“只改阵营交换”“只改 x 镜像”断言改为 V2 的明确语义，满额测试仍为 1200 单位。

`tests/v2-deployment.test.js` 覆盖全部 36 兵种的中线完整半径/安全余量、预览与提交、手势锁队、直线/矩阵裁剪计数、移动/旋转整组回滚、混合选区、实际剪贴板预览、复制/镜像/交换、双侧擦除、完整撤销/重做，以及合法/跨区/损坏/未来版存档保护与显式迁移副本。

这些 Node 测试证明领域层行为。恢复对话框、手机输入、只读预览及实际备份下载的浏览器验收见 `V2-QA-REPORT.md`，不能仅凭 Node 通过宣称界面验收通过。
